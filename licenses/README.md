# Licenses in daemonarchy

This repository is the Daemonarchy installer and is part of the Daemonarchy project. The other repositories are daemonarchy-desktop, daemonarchy-ports, daemonarchy-src and omarchy-freebsd, all under https://github.com/jordanhubbard; the map is in [HACKING.md](../HACKING.md). Daemonarchy-original work is under BSD-2-Clause (see [LICENSE](../LICENSE)). Before this change the repository had no license file except an MIT copy in `apps/daemonarchy-pkg/LICENSE`.

Daemonarchy-original work carries the license terms only, with no copyright notice. Third-party and upstream-derived components keep the upstream notices, which are retained as their licenses require.

This list makes no claim that the licenses of transitive dependencies are represented. It lists the components of this repository and the licenses verified for them, with the evidence for each. The ISO and the package feeds redistribute packages taken from upstream (pkg.FreeBSD.org and the Daemonarchy feed); those packages carry their own license metadata, which is not reproduced here. Firmware the installer can import (Apple Broadcom firmware, see `overlay/usr/local/libexec/daemonarchy-installer/apple-firmware`) is not in this repository and is not licensed by it.

## Texts and their sources

- `BSD-2-Clause.txt`: the SPDX BSD-2-Clause text from spdx/license-list-data (commit 31846481de7ea17d92f2f46fad76abe58b2e9bb0, `text/BSD-2-Clause.txt`), with the template line `Copyright (c) <year> <owner>` removed on the operator's instruction. The rest is unchanged.
- `MIT.txt`: the `LICENSE` of Omarchy (https://github.com/omacom/omarchy, formerly basecamp/omarchy), byte for byte, identical to that repository's head on 2026-10-31. Referenced for Omarchy's `setup-form.sh`, which the image build sources.
- `MIT-omarchy-iso.txt`: the `LICENSE` of https://github.com/omacom/omarchy-iso, byte for byte.
- `ISC.txt`: the `LICENSE` of https://github.com/narqo/freebsd-brcmfmac at tag 9adbe774d3be91827d628fbd811daf63512acb6d, byte for byte.
